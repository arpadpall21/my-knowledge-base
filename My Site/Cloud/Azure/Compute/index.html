Description and Demonstration :

- VM (Virtual Machine) -> Virtual Machine running in the cloud

- Different SKU are available (price VS performance usually)

- "Spot Discount" -> Azure can take back the VM if the capacity is needed (we can have discount up to 80% but we have to be ready for the VM to be taken back) (good for batch processing, data analysis, etc...)

- Availability Options

- Availability Zone -> Explicitly allocate VMs in different zones (so they are physically separated)

- Availability Set -> A logical container where VMs are grouped to ensure high availability

- "Fault Domain" -> A group of VMs sharing common physical infrastructure (rack, power source, network switch)

- "Update Domain" -> A logical group of VMs that Azure updates/reboots together during maintenance (one update domain is updated at a time)

- VM Scale Set -> a group of VMs scalable behind a load balancer

Container Resources:

- Container Registry -> Container storage

- Container Instance -> PaaS Single Container Instance

- Easy to setup container without having to manage the underlying infrastructure (like VMs, load balancers, etc...)

- Container Instance -> PaaS Single Container Instance

- Kubernetes Services -> Kubernetes solution

- App Service (Stack) -> Enterprise grade web application hosting solution

- App Service Plan -> Infrastructure capacity and hosting for our Services (App Service, Function App)

- Here we configure the underlying infrastructure (VMs, scaling, routing, etc...) for our App Services

- App Service -> PaaS Web Application Hosting

- Manages Authentication & Authorization, provides slots for green/blue deployments, manages public routing, etc...

- Function App -> Serverless computing

- Can be triggered by different events (HTTP request, Timer, Storage events (when file up/down loaded))

- Logic Apps -> A series of jobs executed in a workflow

- Azure Logical applications are pre-built apps to perform different tasks (email sending, log, etc...)

- We can make a workflow (with programming features linear, conditional, loop) by using these apps

- We can piece these apps together in a graphical interface
