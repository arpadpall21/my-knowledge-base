Description and Demonstration :

- Microsoft DevOps SaaS echosystem

- Boards -> Jira style ticketing system

- Repos -> Code repositories

- Pipelines -> CI/CD pipelines

- Concepts:

- Trigger -> Action that triggers the pipeline

- Template -> Pipeline script that can be imported and reused

- Agent -> Machine that execute the pipeline jobs

- Agent Pools -> A group of agents

- Artifact -> The output of the pipeline process

- Stage -> A set of jobs representing a functional proces (like test, build, deploy, etc...)

- Job -> A set of steps executed on the same Agent

- Step -> A Task or Script

- Task -> Azure built-in script (like UsePythonVersion@0 sets up a specified Python version)

- Script -> A set of commands executed in bash os PowerShell

- Artifacts -> hosts & shares software packages

- Test Plans -> provides manual testing environments and tools (we can use all sorts of VMs for manual testing)
