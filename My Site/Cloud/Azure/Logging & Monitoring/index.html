Description and Demonstration :

- Azure Monitor -> Echosystem for various azure logging and monitoring services

- Log Analytics Workspace -> Azure Monitor's centralized log data storage for various Azure Monitor services (accessed by Kusto Query Language (KQL))

- Application Insights -> Resource that performance monitor and diagnosis other resource(es) (by default stores data on its own resource)

- Data Collection Rule (DCR) -> Resource that defines what logs & metrics should be collected about a host machine

- It's basicaly a blueprint for data collection (that's why it's a resource )

- defines: whant to collect (CPU, memory, sys logs, etc...), how to transform (filter) and where to send the collected data
